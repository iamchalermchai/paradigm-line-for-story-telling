Plotline Board

คู่มือการใช้งาน — วางเรื่องของคุณลงบนเส้น Paradigm

1 การเซฟ

งานของคุณบันทึกอัตโนมัติลงในเบราว์เซอร์เครื่องนี้ทุกครั้งที่แก้ไข — ไม่มีปุ่มเซฟ ดูสถานะได้ที่มุมขวาบน: บันทึกแล้ว แปลว่าเรียบร้อย

ถ้าต้องการสำรองไฟล์หรือย้ายเครื่อง ใช้เมนู ··· → Export JSON เพื่อดาวน์โหลดโปรเจกต์เป็นไฟล์ แล้วเปิดคืนด้วย Import JSON (การนำเข้าจะแทนที่งานปัจจุบันทั้งหมด)

ล้างข้อมูลเบราว์เซอร์ = งานหาย อย่าลืม Export JSON เก็บไว้เป็นระยะ

2 เขียนการ์ดฉาก

  • กดปุ่ม + Scene ที่แถบบน — การ์ดใหม่จะปรากฏบนกระดาน พร้อมเปิดแผงแก้ไขให้กรอก ชื่อฉาก สถานที่ ตัวละคร เป้าหมาย การกระทำ อุปสรรค และผลลัพธ์
  • ดับเบิลคลิก การ์ดใดก็ได้เพื่อเปิดแผงแก้ไขอีกครั้ง ในแผงมีปุ่ม ทำสำเนา และ ลบฉาก ด้วย
  • คัดลอกการ์ดที่เลือกด้วย ⌘C แล้ววางด้วย ⌘V (Windows ใช้ Ctrl) — ลบการ์ดหรือเส้นที่เลือกด้วย Delete
  • คลิกชื่อฉากในแผงรายการด้านซ้าย (แท็บ Story Action) เพื่อกระโดดไปหาการ์ดนั้นบนกระดาน

3 ลากเส้นเชื่อม

  1. เลือกชนิดเส้นก่อน จากแผง ชนิดเส้น มุมซ้ายบนของกระดาน
  2. ชี้เมาส์ที่การ์ดต้นทาง จะเห็นจุดเชื่อมโผล่ทั้ง 4 ด้าน — ลากจากจุดนั้นไปปล่อยบนการ์ดปลายทาง
  3. คลิกเส้นที่วาดแล้วเพื่อเปิดแผงแก้ไขด้านล่าง: เปลี่ยนชนิด ใส่ป้ายกำกับ หรือลบเส้น

ชนิดเส้นทั้ง 5

  • เหตุการณ์จริง
  • เส้นทาง Want ที่คาดหวัง
  • เส้นทางสู่สิ่งที่ดีกว่า / Need
  • ความล้มเหลว / ไม่ได้ Want
  • เส้นทาง Character Arc

4 วางบนไทม์ไลน์

กระดานคือไทม์ไลน์ของเรื่อง แบ่งเป็นช่วงตามโครงสร้างที่เลือกไว้ (ค่าเริ่มต้นคือ 4 ช่วง: เริ่มต้น → ช่วงแรก → ช่วงกลาง → ช่วงท้าย) โดยมีเส้น Paradigm พาดแนวนอนตรงกลาง

  • ลากซ้าย–ขวา เพื่อเลื่อนฉากไปช่วงอื่นของเรื่อง — ช่วง (Phase) ของฉากเปลี่ยนตามตำแหน่งอัตโนมัติ
  • เหนือเส้น = ฉากที่ขับด้วย Lie / Want · ใต้เส้น = ฉากที่ขับด้วย Ghost / Need
  • หมุด Beat (Catalyst, Midpoint, Climax …) เกาะอยู่บนเส้น ลากได้เฉพาะแนวนอน — ชุดหมุดมาจากโครงสร้างที่เลือก (ดูหัวข้อ 5)
  • ปุ่ม จัดเรียงอัตโนมัติ ที่แถบบน จัดผังทั้งกระดานให้ทันที (กดปุ่มเลิกทำ เพื่อย้อนกลับได้)
  • สลับมุมมอง เวลาในเรื่อง / ลำดับเล่า ที่มุมซ้ายบนของกระดาน เพื่อดูลำดับเหตุการณ์จริง เทียบกับลำดับการเล่า — และติ๊ก จับแนวกริด ที่มุมขวาบน ถ้าอยากให้การ์ดเรียงเป็นระเบียบ

5 โครงสร้างเรื่อง

แผง โครงสร้าง มุมซ้ายบนของกระดาน ไม่ได้เปลี่ยนแค่ป้ายหัวคอลัมน์ — เลือกโครงสร้างไหน กระดานจะวางหมุด Beat ชุดของโครงสร้างนั้นลงบนเส้น Paradigm ให้ทันที ช่องแบ่งช่วงเปลี่ยนตาม และช่อง Story Beat ในแผงแก้ไขฉากก็เปลี่ยนตัวเลือกตามไปด้วย

สลับได้ตลอดเวลา ไม่มีอะไรหาย: การ์ดอยู่ตำแหน่งเดิม แท็ก Beat ที่เคยใส่ไว้ยังติดกับฉาก (สลับกลับมาก็เห็นเหมือนเดิม) และถ้าไม่ชอบก็กดปุ่มเลิกทำได้ ส่วนหมุดที่คุณล็อกตำแหน่งไว้ หรือหมุดที่เพิ่มเองจะไม่ถูกแทนที่

4 Phase

1. เริ่มต้น · 2. ช่วงแรก · 3. ช่วงกลาง · 4. ช่วงท้าย

โครงเรื่องแบบ Paradigm ที่ผูกทุกฉากไว้กับบาดแผลของตัวละคร — เหมาะกับเรื่องที่คนอ่านต้องเปลี่ยนไปพร้อมตัวละคร

เริ่มที่นี่ · ตั้งต้นที่ตัวละครก่อนเหตุการณ์: กรอก Ghost / Lie / Want / Need ในแท็บ Backstory ให้ได้ก่อน แล้วค่อยหาว่าฉากไหนทำให้ Lie ทำงาน และฉากไหนบังคับให้เห็น Need

Kishōtenketsu

起 Ki · เปิดโลก — 承 Shō · ขยายความ — 転 Ten · จุดพลิก — 結 Ketsu · คลี่คลาย

โครงสี่ขั้นแบบเอเชียตะวันออกที่ไม่ต้องมีความขัดแย้งเป็นเครื่องยนต์ — เหมาะกับเรื่องสั้น เรื่องชีวิต และงานที่เดินด้วยการเปลี่ยนมุมมอง

เริ่มที่นี่ · หา 転 Ten ให้ได้ก่อนเป็นอย่างแรก: อะไรที่โผล่เข้ามาแล้วทำให้ทุกอย่างก่อนหน้ามีความหมายใหม่ เมื่อได้จุดนั้นแล้วจึงถอยกลับไปเขียน 起 กับ 承 ให้เป็นชีวิตปกติที่เงียบพอจะถูกพลิก

หมุด: 起 เปิดโลก · 承 ขยายความ · 転 จุดพลิก · 結 คลี่คลาย — สังเกตว่ามีหมุดหลักตัวเดียวคือ Ten เพราะโครงนี้เดินด้วยการพลิกมุมมอง ไม่ใช่การเอาชนะ

ยังไม่รู้จะใช้อันไหน? ถ้าเรื่องของคุณเดินด้วยความอยากของตัวละคร เริ่มที่ 4 Phase — ถ้าเดินด้วยบรรยากาศหรือการค่อยๆ เข้าใจอะไรบางอย่าง ลอง Kishōtenketsu ที่ไม่บังคับให้มีศัตรู

6 ตัวอย่างการใช้งาน

เริ่มเรื่องใหม่หนึ่งเรื่อง ครบใน 6 ขั้น:

  1. 1เลือกโครงสร้าง — ที่แผง "โครงสร้าง" มุมซ้ายบน หมุด Beat ของโครงสร้างนั้นจะมาวางบนเส้นให้เป็นโครงร่างว่าต้องเติมอะไร
  2. 2ปูพื้นตัวละคร — กรอก Ghost / Lie / Want / Need ในแท็บ Backstory ด้านซ้าย ให้กระดานรู้ว่าแกนเรื่องคืออะไร
  3. 3สร้างฉากสำคัญ — กด + Scene สัก 5–6 ฉาก กรอกอย่างน้อยชื่อฉากกับการกระทำ (Action) ของแต่ละฉาก
  4. 4วางลงไทม์ไลน์ — ลากการ์ดไปให้อยู่ใต้หมุด Beat ที่ตรงกับมัน ฉากที่ตัวละครไล่ตาม Want ไว้เหนือเส้น ฉากที่แผล Ghost ทำงานไว้ใต้เส้น
  5. 5ลากเส้นเชื่อมเรื่อง — เลือกชนิดเส้น "เหตุการณ์จริง" แล้วเชื่อมฉากตามลำดับ จากนั้นใช้เส้นชนิดอื่นวาดทางแยกที่คาดหวัง / ล้มเหลว
  6. 6ตรวจและแชร์ — สลับไปมุมมอง "ลำดับเล่า" ตรวจลำดับการเล่า แล้วใช้ Export PNG ในเมนู ··· เพื่อแชร์กระดานเป็นภาพ

จะโพสต์ลงเฟซบุ๊ก? ในหน้าต่าง Export PNG เลือก แบ่งเป็นหลายภาพ — เฟซบุ๊กย่อทุกภาพเหลือ 2048px กระดานใหญ่ในภาพเดียวจะอ่านไม่ออก แบบแบ่งภาพจะตัดกระดานเป็นช่วงๆ ให้ยังอ่านชัด แล้วอัปโหลดเป็นอัลบั้มในโพสต์เดียวได้เลย
