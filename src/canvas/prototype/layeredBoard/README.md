# PROTOTYPE — Layered board (META / CHARACTER / MEMORY / GHOST)

**Question:** เลน Y สี่แถว + ลูกศรกระตุ้นข้ามเลน อ่านได้บน cream board ไหม — โดยไม่แทนที่ Paradigm Line ทั้งแอป?

Switch: `npm run prototype:layers` → `/?layers=A|B|C`

| Key | Thesis |
|-----|--------|
| A | สี่เลนเท่ากัน + ป้ายซ้าย (ใกล้ภาพอ้างอิง) |
| B | CHARACTER เป็นแกนหนา · META บาง · MEMORY/GHOST เป็นสนามใต้เส้น |
| C | ไม่มีแถบเลน — สีวง/เพชร + เส้นบอกชั้น |

Sample nodes are fake; no store writes. DEV only.
