คู่มือการใช้งาน — วางเรื่องของคุณลงบนเส้น Paradigm

1 การเซฟ

งานของคุณบันทึกอัตโนมัติลงในเบราว์เซอร์เครื่องนี้ทุกครั้งที่แก้ไข — ไม่มีปุ่มเซฟ ดูสถานะได้ที่มุมขวาบน: บันทึกแล้ว แปลว่าเรียบร้อย

ถ้าต้องการสำรองไฟล์หรือย้ายเครื่อง ใช้เมนู ··· → Export JSON เพื่อดาวน์โหลดโปรเจกต์เป็นไฟล์ แล้วเปิดคืนด้วย Import JSON (การนำเข้าจะแทนที่งานปัจจุบันทั้งหมด)

ล้างข้อมูลเบราว์เซอร์ = งานหาย อย่าลืม Export JSON เก็บไว้เป็นระยะ

2 เขียนการ์ดฉาก

  • กดปุ่ม + Scene ที่แถบบน — การ์ดใหม่จะปรากฏบนกระดาน พร้อมเปิดแผงแก้ไขให้กรอก ชื่อฉาก สถานที่ ตัวละคร เป้าหมาย การกระทำ อุปสรรค และผลลัพธ์
  • ดับเบิลคลิก การ์ดใดก็ได้เพื่อเปิดแผงแก้ไขอีกครั้ง ในแผงมีปุ่ม ทำสำเนา และ ลบฉาก ด้วย
  • คัดลอกการ์ดที่เลือกด้วย ⌘C แล้ววางด้วย ⌘V (Windows ใช้ Ctrl) — ลบการ์ดหรือเส้นที่เลือกด้วย Delete
  • คลิกชื่อฉากในแผงรายการด้านซ้าย (แท็บ Story Action) เพื่อกระโดดไปหาการ์ดนั้นบนกระดาน

3 ลากเส้นเชื่อม

  1. เลือกชนิดเส้นก่อน — เปิดแท็บคั่นหน้า ชนิด ที่ขอบซ้ายของกระดาน
  2. ชี้เมาส์ที่การ์ดต้นทาง จะเห็นจุดเชื่อมโผล่ทั้ง 4 ด้าน — ลากจากจุดนั้นไปปล่อยบนการ์ดปลายทาง
  3. คลิกเส้นที่วาดแล้วเพื่อเปิดแผงแก้ไขด้านล่าง: เปลี่ยนชนิด ใส่ป้ายกำกับ หรือลบเส้น

ชนิดเส้นทั้ง 5

  • เหตุการณ์จริง
  • เส้นทาง Want ที่คาดหวัง
  • เส้นทางสู่สิ่งที่ดีกว่า / Need
  • ความล้มเหลว / ไม่ได้ Want
  • เส้นทาง Character Arc

4 วางบนไทม์ไลน์

กระดานคือไทม์ไลน์ของเรื่อง แบ่งเป็นช่วงตามโครงสร้างที่เลือกไว้ (ค่าเริ่มต้นคือ 4 ช่วง: เริ่มต้น → ช่วงแรก → ช่วงกลาง → ช่วงท้าย) โดยมีเส้นแกนพาดแนวนอนตรงกลาง — ชื่อเส้นและความหมายเหนือ/ใต้เส้นเปลี่ยนตามโครงที่เลือก (เช่น 4 Phase ใช้ Paradigm Line กับ Lie/Want · Ghost/Need ส่วน Hero's Journey ใช้เส้นการเดินทางกับการผจญภัยภายนอก · การเปลี่ยนแปลงภายใน)

  • ลากซ้าย–ขวา เพื่อเลื่อนฉากไปช่วงอื่นของเรื่อง — ช่วง (Phase) ของฉากเปลี่ยนตามตำแหน่งอัตโนมัติ
  • เหนือเส้น / ใต้เส้น อ่านตามป้ายของโครงปัจจุบัน — ใช้วางฉากที่ขับด้วยแรงภายนอกไว้เหนือเส้น และฉากที่แตะความจริงภายในไว้ใต้เส้น
  • หมุด Beat (Catalyst, Midpoint, Climax …) เกาะอยู่บนเส้น ลากได้เฉพาะแนวนอน — ชุดหมุดมาจากโครงสร้างที่เลือก (ดูหัวข้อ 5)
  • ปุ่ม จัดเรียงอัตโนมัติ ที่แถบบน จัดผังทั้งกระดานให้ทันที (กดปุ่มเลิกทำ เพื่อย้อนกลับได้)
  • เครื่องมือกระดานอยู่ที่แท็บคั่นหน้าขอบซ้าย (เปิดใบเมื่อกด พับเข้าได้): เวลา = ลำดับเหตุการณ์จริง · เล่า = ลำดับการเล่า · โครง = เลือกโครงสร้างและอ่านคู่มือช่วง · ชนิด = เลือกชนิดเส้นก่อนลากเชื่อม · เส้น = ความหมายเหนือ/ใต้เส้นของโครงปัจจุบัน
  • ติ๊ก จับแนวกริด ที่มุมขวาบน ถ้าอยากให้การ์ดเรียงเป็นระเบียบ

5 โครงสร้างเรื่อง

เมื่อเปิดกระดานว่าง แอปจะถามให้เลือกโครงก่อนครั้งหนึ่ง (ข้ามได้ — ค่าเริ่มต้นคือ 4 Phase) หลังจากนั้นเปิดแท็บคั่นหน้า โครง ที่ขอบซ้ายได้ตลอด การเลือกไม่ได้เปลี่ยนแค่ป้ายหัวคอลัมน์ — เลือกโครงสร้างไหน กระดานจะวางหมุด Beat ชุดของโครงสร้างนั้นลงบนเส้น ให้ทันที ช่องแบ่งช่วงและป้ายเหนือ/ใต้เส้นเปลี่ยนตาม และช่อง Story Beat ในแผงแก้ไขฉากก็เปลี่ยนตัวเลือกตามไปด้วย

สลับได้ตลอดเวลา ไม่มีอะไรหาย: การ์ดอยู่ตำแหน่งเดิม แท็ก Beat ที่เคยใส่ไว้ยังติดกับฉาก (สลับกลับมาก็เห็นเหมือนเดิม) และถ้าไม่ชอบก็กดปุ่มเลิกทำได้ ส่วนหมุดที่คุณล็อกตำแหน่งไว้ หรือหมุดที่เพิ่มเองจะไม่ถูกแทนที่

4 Phase

1. เริ่มต้น · 2. ช่วงแรก · 3. ช่วงกลาง · 4. ช่วงท้าย

โครงเรื่องแบบ Paradigm ที่ผูกทุกฉากไว้กับบาดแผลของตัวละคร — เหมาะกับเรื่องที่คนอ่านต้องเปลี่ยนไปพร้อมตัวละคร

Paradigm Line · ↑ Lie · Want · ↓ Ghost · Need

เริ่มที่นี่ · ตั้งต้นที่ตัวละครก่อนเหตุการณ์: กรอก Ghost / Lie / Want / Need ในแท็บ Backstory ให้ได้ก่อน แล้วค่อยหาว่าฉากไหนทำให้ Lie ทำงาน และฉากไหนบังคับให้เห็น Need

โครงนี้เดินด้วยบาดแผลและคำโกหกที่ตัวละครเชื่อ — ทุกฉากควรถามว่ากำลังเลี้ยง Lie หรือบีบให้เห็น Need เหตุการณ์ไม่ได้เรียงแค่ "แล้วก็" แต่ต้องเป็น "เพราะฉะนั้น / แต่" ที่ทำให้เดิมพันสูงขึ้นจนเลือกทางใหม่ไม่ได้หลีก

  • 1. เริ่มต้น
    งาน · ปูชีวิตปกติและแผลที่ยังไม่ถูกชำระ ก่อนโลกจะพัง
    ควรใส่ · ฉากที่โชว์ Lie ทำงานในชีวิตประจำวัน Ghost ที่ยังหลบอยู่ และเหตุ Catalyst ที่ทำให้สถานะเดิมอยู่ต่อไม่ได้
    เป้าจบช่วง · คนอ่านรู้ว่าตัวละครเป็นใคร เชื่ออะไรผิด และทำไมต้องเริ่มไล่ตาม Want
  • 2. ช่วงแรก
    งาน · ให้ Lie กับ Want ยังใช้ได้ผล จนตัวละครมั่นใจเกินจริง
    ควรใส่ · ฉากที่แผนเดิมสำเร็จ Things Go Well คำเตือนแรกที่ยังถูกละเลย และการประกาศ Want ชัดๆ
    เป้าจบช่วง · คนอ่านเชื่อว่าวิธีเดิมใช้ได้ — พอจะเจ็บเมื่อมันพังในระยะถัดไป
  • 3. ช่วงกลาง
    งาน · ขึ้นราคาของ Lie ให้ Ghost ขัดขา และตัดทางถอย
    ควรใส่ · ฉาก Midpoint ที่เดิมพันเปลี่ยน Ghost ที่ย้อนกลับมา และ Low Point ที่แพงที่สุดของการยึด Lie
    เป้าจบช่วง · ตัวละครถอยกลับไปเป็นคนเดิมไม่ได้แล้ว — เหลือแต่การเผชิญความจริง
  • 4. ช่วงท้าย
    งาน · บังคับให้เลือก Need แล้วลงมือโดยไม่มีตาข่าย
    ควรใส่ · ฉาก Aha / Choice / Climax / Ending ที่พิสูจน์ว่าตัวละครเปลี่ยนจริง ไม่ใช่แค่พูด
    เป้าจบช่วง · ชีวิตหลังจบวัดได้ว่าต่างจากตอนเปิด — Want กับ Need ลงเอยชัด

Three Act

Act 1 · Setup — Act 2 · Confrontation — Act 3 · Resolution

สามองก์แบบคลาสสิก โครงที่กว้างและยืดหยุ่นที่สุด — เหมาะเมื่ออยากเห็นภาพรวมก่อนลงรายละเอียด

เส้นเรื่อง · ↑ ภายนอกที่ไล่ตาม · ↓ ความจริงภายใน

เริ่มที่นี่ · ปักสองหมุดให้ได้ก่อน: Inciting Incident ที่เปิดปัญหา และ Climax ที่ปิดมัน แล้วถามว่าอะไรทำให้ระยะกลางยาวขนาดนั้น — คำตอบคือ Midpoint

สามองก์คือกรอบกว้าง: เปิดปัญหา ยืดด้วยการปะทะ แล้วปิดด้วยการเผชิญหน้า ใช้เมื่ออยากเห็นภาพรวมก่อนลงบีตรายละเอียด — ทุกองก์ต้องมีคำถามที่ค้างและ stake ที่สูงขึ้น ไม่ใช่แค่แบ่งหน้าเป็นสามก้อน

  • Act 1 · Setup
    งาน · แนะนำโลก ปัญหา และทางเข้าสู่เรื่อง
    ควรใส่ · ฉากชีวิตก่อนพายุ Inciting Incident และ Plot Point 1 ที่ตัวละครเลือกก้าวเข้าโลกใหม่
    เป้าจบช่วง · คำถามหลักของเรื่องถูกวาง และตัวละครไม่สามารถกลับไปสถานะเดิมได้โดยไม่มีราคา
  • Act 2 · Confrontation
    งาน · ยืดการปะทะ ยกระดับ stake และพลิกกลางเรื่อง
    ควรใส่ · ฉากลองผิดลองถูก อุปสรรคซ้อน Midpoint ที่พลิกจากตั้งรับเป็นรุก และแรงกดจนถึง Plot Point 2
    เป้าจบช่วง · ทางเลือกหมดลง เหลือทางเดียวคือเผชิญหน้า — คนอ่านรู้ว่าทำไมองก์สามต้องเกิด
  • Act 3 · Resolution
    งาน · ตอบคำถามหลักแล้วโชว์โลกหลังพายุ
    ควรใส่ · ฉาก Climax ที่ลงมือตัดสิน และ Resolution ที่ให้เห็นอะไรเปลี่ยนไปจริง
    เป้าจบช่วง · คำถามเปิดเรื่องถูกตอบ และการเปลี่ยนแปลงวัดได้จากชีวิตหลังจบ

Kishōtenketsu

起 Ki · เปิดโลก — 承 Shō · ขยายความ — 転 Ten · จุดพลิก — 結 Ketsu · คลี่คลาย

โครงสี่ขั้นแบบเอเชียตะวันออกที่ไม่ต้องมีความขัดแย้งเป็นเครื่องยนต์ — เหมาะกับเรื่องสั้น เรื่องชีวิต และงานที่เดินด้วยการเปลี่ยนมุมมอง

เส้น 起承転結 · ↑ โลกตามที่เล่า · ↓ ความหมายที่ถูกพลิก

เริ่มที่นี่ · หา 転 Ten ให้ได้ก่อนเป็นอย่างแรก: อะไรที่โผล่เข้ามาแล้วทำให้ทุกอย่างก่อนหน้ามีความหมายใหม่ เมื่อได้จุดนั้นแล้วจึงถอยกลับไปเขียน 起 กับ 承 ให้เป็นชีวิตปกติที่เงียบพอจะถูกพลิก

Kishōtenketsu ไม่ใช้ความขัดแย้งเป็นเครื่องยนต์ — พลังอยู่ที่การพลิกมุมมอง 起 กับ 承 ต้องเงียบและจริงพอที่ 転 จะเปลี่ยนความหมายของทุกอย่างก่อนหน้า ส่วน 結 ไม่ใช่การเอาชนะ แต่คือการวางสองภาพไว้ข้างกันจนคนอ่านเห็นภาพรวมใหม่

  • 起 Ki · เปิดโลก
    งาน · แนะนำผู้คนและสถานที่ตามที่เป็นอยู่
    ควรใส่ · ฉากชีวิตปกติ รายละเอียดโลก และความสัมพันธ์ที่ยังไม่ถูกบีบด้วยปัญหาใหญ่

6 ตัวอย่างการใช้งาน

เริ่มเรื่องใหม่หนึ่งเรื่อง ครบใน 6 ขั้น:

  1. 1เลือกโครงสร้าง — ตอบหน้าต่างเลือกโครงตอนกระดานว่าง (หรือเปิดแท็บคั่นหน้า "โครง" ที่ขอบซ้ายทีหลัง) หมุด Beat จะมาวางบนเส้นให้เป็นโครงร่างว่าต้องเติมอะไร
  2. 2ปูพื้นตัวละคร — กรอก Ghost / Lie / Want / Need ในแท็บ Backstory ด้านซ้าย แล้วตั้งผลลัพธ์ตอนจบ (Want / Need) — ด้านล่างมี "หลักฐานบนกระดาน" สรุปฉาก climax และเส้น Want→ · Need→ · Fail→ ที่ชี้เข้าฉากนั้น
  3. 3สร้างฉากสำคัญ — กด + Scene สัก 5–6 ฉาก กรอกอย่างน้อยชื่อฉากกับการกระทำ (Action) — ฉากจบให้แท็ก Story Beat เป็น climax / finale / resurrection / ordeal เพื่อให้หลักฐานบนกระดานจับได้
  4. 4วางลงไทม์ไลน์ — ลากการ์ดไปให้อยู่ใต้หมุด Beat ที่ตรงกับมัน ฉากที่ตัวละครไล่ตาม Want ไว้เหนือเส้น ฉากที่แผล Ghost ทำงานไว้ใต้เส้น
  5. 5ลากเส้นเชื่อมเรื่อง — เปิดแท็บ "ชนิด" เลือกเส้น "เหตุการณ์จริง" แล้วเชื่อมฉากตามลำดับ จากนั้นใช้เส้นชนิดอื่นวาดทางแยกที่คาดหวัง / ล้มเหลวเข้าฉาก climax
  6. 6ตรวจและแชร์ — เปิดแท็บ "เล่า" ตรวจลำดับการเล่า เทียบหลักฐานบนกระดานกับผลลัพธ์ตอนจบที่เลือก แล้วใช้ Export PNG ในเมนู ··· เพื่อแชร์กระดานเป็นภาพ

จะโพสต์ลงเฟซบุ๊ก? ในหน้าต่าง Export PNG เลือก แบ่งเป็นหลายภาพ — เฟซบุ๊กย่อทุกภาพเหลือ 2048px กระดานใหญ่ในภาพเดียวจะอ่านไม่ออก แบบแบ่งภาพจะตัดกระดานเป็นช่วงๆ ให้ยังอ่านชัด แล้วอัปโหลดเป็นอัลบั้มในโพสต์เดียวได้เลย
